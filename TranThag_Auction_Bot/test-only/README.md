# TEST-ONLY AuctionEngine

This folder contains the user's requested AuctionEngine/RobloxService logic in an isolated local test harness.

- It is not connected to TikTok LIVE.
- It does not post public chat messages.
- It does not replace the production AuctionEngine.
- Run locally with: `node run-test.cjs`

The service code preserves the requested class/function structure and behavior for simulation.
